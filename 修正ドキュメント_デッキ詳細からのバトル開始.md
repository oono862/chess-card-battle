# デッキ詳細画面からのバトル開始時のデッキ情報保持修正

## 問題
ユーザーが「デッキ4」を選択 → 詳細画面を表示 → 画面から戻る → スタート画面で難易度を選び直す
という流れの場合、最初に選んだ「デッキ4」の情報が失われ、代わりに24枚の固定デッキが使われていた。

## 根本原因
`show_deck_modal(battle_select_mode=False)` でユーザーが「デッキ詳細」を見て戻った場合、
デッキ選択情報が保存されず、その後スタート画面で難易度選択時に `DECK_MODE='fixed'` がデフォルトで使用されていた。

### コードの流れ
```
1. show_deck_modal(battle_select_mode=False) 
   ↓
2. show_deck_action_modal(screen, deck, slot_idx)
   ↓
3. User clicks "デッキ詳細" button
   ↓
4. show_deck_contents_overlay(screen, deck)
   ↓
5. User closes overlay → Returns to show_deck_action_modal
   ↓
6. show_deck_action_modal returns None
   ↓
7. show_deck_modal loops back and waits for next action
   ↓
8. User closes show_deck_modal (clicks back/escape)
   ↓
9. show_deck_modal returns to show_start_screen()
   ↓
10. show_start_screen loops, DECK_MODE has not been set to 'custom'!
    ↓
11. User clicks difficulty button
    ↓
12. show_deck_choice_modal() sets DECK_MODE (user must choose again)
    ↓
13. If user selects fixed deck, game uses 24 cards instead of custom 20
```

## 修正内容

### 1. グローバル変数追加 (line 538-544)
```python
# 最後に選択されたカスタムデッキの情報（デッキ詳細を見た後にバトル開始する場合に使用）
_selected_deck_slot_idx = None
_selected_deck_card_names = None
```

### 2. show_deck_action_modal 修正 (line ~2299)
「デッキ詳細」ボタンから戻る際に、デッキ情報をグローバル変数に保存:
```python
if view_rect.collidepoint(mx, my):
    show_deck_contents_overlay(screen, deck)
    # After viewing deck details, save the deck info
    global _selected_deck_slot_idx, _selected_deck_card_names
    _selected_deck_slot_idx = slot_idx
    card_names = []
    for c in deck.get('cards', []):
        if isinstance(c, dict):
            card_names.append(str(c.get('name', '')))
        else:
            card_names.append(str(c))
    _selected_deck_card_names = card_names
    logger.debug("Saved deck info: slot=%d, cards=%s", slot_idx, card_names[:3])
    continue
```

### 3. show_start_screen 修正 (2箇所: キーボード入力とマウスクリック)
難易度選択後、`DECK_MODE == 'custom'` の場合に保存されたデッキ情報を確認:
```python
if DECK_MODE == 'custom':
    # Check if user previously selected a deck by viewing its details
    global _selected_deck_card_names, _selected_deck_slot_idx
    if _selected_deck_card_names:
        # Use the previously selected deck
        logger.debug("Using previously selected deck with cards=%s", _selected_deck_card_names[:3])
        if 'build_game_from_card_names' in globals():
            g = build_game_from_card_names(_selected_deck_card_names)
            if g is not None:
                globals()['game'] = g
                globals()['ai_player'] = build_ai_player('custom')
                try:
                    _init_ai_start_hand(globals()['ai_player'], 4, globals()['game'])
                except Exception:
                    pass
                # Clear the saved deck info after using it
                _selected_deck_card_names = None
                _selected_deck_slot_idx = None
                return
            else:
                # Fallback: show deck list for user to pick manually
                logger.debug("build_game_from_card_names failed, showing deck list")
                _selected_deck_card_names = None
                _selected_deck_slot_idx = None
    # Show deck list for user to pick manually
    started = show_deck_modal(screen, battle_select_mode=True)
    ...
```

## 修正後の動作

### シナリオ1: デッキ詳細を見てから難易度選択
```
1. User selects "デッキ4" from list
2. show_deck_action_modal appears with edit/view/delete buttons
3. User clicks "デッキ詳細" button
4. show_deck_contents_overlay appears showing card images
5. User clicks outside to close overlay
6. Deck info is saved to _selected_deck_card_names, _selected_deck_slot_idx
7. User clicks back/escape to exit show_deck_modal
8. show_start_screen is displayed
9. User clicks difficulty button (e.g., "2 - ノーマル")
10. show_deck_choice_modal appears
11. User clicks "作成したデッキ（暫定）"
12. DECK_MODE = 'custom'
13. Check: _selected_deck_card_names is set? YES!
14. Create game with build_game_from_card_names(_selected_deck_card_names)
15. Game starts with correct 20-card custom deck
16. Clear the saved info: _selected_deck_card_names = None
```

### シナリオ2: 直接デッキリストからバトル開始（既存動作）
```
1. show_start_screen appears
2. User clicks difficulty button
3. show_deck_choice_modal appears
4. User clicks "作成したデッキ（暫定）"
5. DECK_MODE = 'custom'
6. Check: _selected_deck_card_names is set? NO
7. Show deck list: show_deck_modal(screen, battle_select_mode=True)
8. User picks deck and clicks "バトル開始"
9. Game starts with selected custom deck
```

### シナリオ3: 途中でデッキ選択をリセット
```
- If user navigates back and selects a different deck slot's details,
  _selected_deck_card_names will be overwritten with new deck info
- This ensures the most recently viewed deck is always used
```

## ログ出力
修正されたコードは以下のデバッグログを出力します:
- `"Saved deck info: slot=%d, cards=%s"` : デッキ詳細を見た時
- `"Using previously selected deck with cards=%s"` : 保存されたデッキを使う時
- `"build_game_from_card_names failed, showing deck list"` : フォールバック時

これらのログを確認することで、修正が正しく動作しているか確認できます。

## 副作用なし
- 既存の「直接デッキ選択→バトル開始」フローは変更なし
- グローバル変数は使用後にクリアされるため、他のゲームセッションに影響しない
- fallbackロジックが存在するため、カード名マッピングエラーが発生した場合でも手動選択に移行できる
